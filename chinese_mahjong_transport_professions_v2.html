1. Собери иероглиф из двух частей

Иероглиф заранее не показан. Найди две части. Верный иероглиф появится внизу.

Выбери две плитки.
Полученные иероглифы

2. Найди нужный иероглиф

Дан pinyin и слово с пропуском. Выбери нужный иероглиф. Порядок заданий случайный.

Выбери иероглиф.

3. Найди слово по pinyin

Найди правильное слово среди визуально похожих вариантов. Например: 电车 / 电东 / 由东 / 油车.

Выбери слово.

4. Расставь иероглифы в правильном порядке

Нажимай на плитки по порядку. Если у предложения есть несколько естественных вариантов порядка слов, они тоже засчитываются как правильные.

Собери предложение.
