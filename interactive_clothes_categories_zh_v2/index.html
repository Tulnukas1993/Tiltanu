Интерактивное задание по китайскому

Одежда, счётные слова и категории лексики

1. Соотнеси иероглифы с картинками

Нажми слово снизу, затем поле рядом с подходящей картинкой.

Выбери слово.

2. Распредели слова по счётным словам

Перетащи слова в 一件, 一条 или 一双.

一件

一条

一双

Распредели все слова.

3. Собери слова из иероглифов и распредели по категориям

Нажимай крупные плитки-иероглифы по порядку. Готовое слово перенеси в нужную категорию.

—
