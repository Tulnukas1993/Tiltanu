Lisez le dialogue. Sélectionnez les expressions de comparaison et les superlatifs.

Нажмите на фрагмент, чтобы выделить его; повторное нажатие снимает выделение. Можно нажимать и на другие части текста: цвет заранее не подсказывает ответ.

Comprendre les formes

autant d’expérience que / plus d’expérience : quantité.
aussi compétent que / moins dynamique que : qualité.
mieux / mieux que : manière de faire.
meilleur / la meilleure : comparaison avec bon / bonne.
comme moi : ressemblance.
le plus jeune : superlatif.
