1. Собери иероглиф из частей

Иероглиф заранее не показывается. Выбери две части; после правильной пары готовый иероглиф появится внизу.

Выбери две плитки.
Полученные иероглифы

2. Собери слово по pinyin

Сверху дан только pinyin. Нужные иероглифы спрятаны в двух колонках и перемешиваются. Нажимай на них по порядку.

Собери слово.

3. Вставь слова в предложения

Упражнение по первому скриншоту. Используй каждое слово один раз.

1. 我喜欢 ______ 和 ______。
2. 弟弟 ______ 九点 ______。
3. 今天 ______ 二日 ______ 四。
4. 妹妹坐 ______ ______。
5. 姐姐喜欢穿 ______ 和 ______。
6. 他 ______ 是美国人，一半是 ______。
Сначала нажми на пропуск, затем на слово.

4. Найди иероглифы по ключу

Упражнение по второму скриншоту. Выбери ключ, затем нажимай на подходящие иероглифы.

Выбери строку с ключом.
