练习18 部件拼字 找颜色

1. 练习18 · 填空

Над каждым пропуском показан пиньинь. Нажми на иероглиф внизу, затем на нужный пропуск. Есть похожие отвлекающие знаки.

2. 部件拼字 · выбери 2 элемента

Выбери строку, затем один ключ из левой таблицы и один элемент из правой. Только после правильной сборки появляется готовый иероглиф. Ищем: 红 黑 棕 橙 黄 白 蓝 绿 粉 颜.

红 = красный黑 = чёрный棕 = коричневый橙 = оранжевый黄 = жёлтый 白 = белый蓝 = синий绿 = зелёный粉 = розовый颜 = цвет / лицо

Выбери слово и собери его

① Ключи · 部首

② Остальные части · 部件

3. 找颜色 · найди нужный иероглиф по цвету

Смотри на цветной квадрат и выбирай правильный иероглиф. Под каждым квадратом 10 похожих вариантов. Здесь отрабатываем: 红 黑 棕 橙 黄 白 蓝 绿.
