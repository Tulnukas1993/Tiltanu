# Das Duell der Brüder

Интерактивный учебный документ по немецкому языку: история семьи Дасслер, Adidas и Puma.

Полный текст и задания перепечатаны с трёх предоставленных пользователем изображений. Подобраны три фотографии с указанием источников. Русские пояснения и мини-словарь добавлены для самостоятельной работы.

## Как открыть

Откройте [урок в браузере](https://tulnukas1993.github.io/Tiltanu/german_das_duell_der_brueder.html). Для работы без интернета скачайте файл german_das_duell_der_brueder.html из корня репозитория или index.html из этой папки: текст, изображения, стили и проверка ответов встроены в один файл.

Файл german_das_duell_der_brueder.html в корне репозитория автоматически появляется в немецком разделе библиотеки Tiltanu.

## Что внутри

- Полный текст «Das Duell der Brüder» и три иллюстрации.
- 6 вопросов с выбором ответа, 4 соответствия и 14 предложений в Präteritum.
- Проверка 24 ответов и 87 подготовленных вариантов порядка слов в Präteritum.
- Пояснения, образцы ответов, личный словарь и выделение незнакомых слов.
- Сохранение прогресса в браузере, скачивание HTML с текущими ответами, печать и PDF.
- Озвучивание текста при наличии немецкого голоса в браузере.

Текст, изображения и проверка работают без интернета. Озвучивание зависит от возможностей браузера; внешние ссылки на источники требуют интернета. Ответы и заметки хранятся в браузере и не отправляются на сервер.

## Исходники

| Файл | Назначение |
| --- | --- |
| index.html | Готовый автономный документ |
| dist/index.html | Та же версия для статического хостинга |
| template.html | Разметка, оформление и интерактивность |
| build.py | Текст, ключи, допустимые ответы и сборка |
| lesson-data.json | Данные урока, сформированные при сборке |
| assets/ | Исходные фотографии |
| CREDITS.md | Авторы изображений и сведения о правах |

После изменения исходников выполните:

```sh
cd das-duell-der-brueder
python3 build.py
```

Используется только стандартная библиотека Python. Скрипт пересоздаёт index.html, dist/index.html, lesson-data.json и ../german_das_duell_der_brueder.html.

## Проверка

Проверены структура HTML, синтаксис JavaScript, все 24 ключа, 87 вариантов предложений, отклонение 14 примеров с грамматическими ошибками, сохранение и восстановление прогресса, скачивание и повторное открытие заполненного HTML, словарь и очистка ответов. Интерактивная логика проверена в JSDOM. Визуальная проверка браузером в среде создания была недоступна.

Проверка свободных предложений основана на подготовленных вариантах. Другой грамматически верный порядок слов может потребовать самостоятельного сравнения с образцом.

## Материалы и права

Текст и упражнения взяты из изображений, предоставленных пользователем. Их первоначальный издатель в исходниках не указан. Сведения об изображениях и их лицензиях находятся в CREDITS.md и в самом документе. Единая свободная лицензия на все материалы не заявляется.
